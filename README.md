# Eleva Studio

Base organizada para desenvolver o site da Eleva Studio seção por seção.

## Estrutura

```text
app/
  layout.tsx
  page.tsx
  globals.css
components/
  layout/       # Navbar, Footer e estrutura global
  sections/     # Seções específicas da página
  ui/           # Elementos reutilizáveis compartilhados
public/
  images/
    hero/
    logo/
```

## Executar localmente

Requer Node.js 18.17 ou superior.

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Como vamos trabalhar

A base inclui um Hero inicial com gradientes em CSS, Navbar responsiva, Footer e configurações do projeto. O background fluido interativo, o design final e as demais seções serão aprimorados de forma incremental. Não há vídeo de introdução.
